# 🔧 JOM — Mechanic Workshop App

A full-stack web application for managing an automobile repair workshop.
JOM helps customers find mechanics, book services, and manage repairs
across all car brands.

## 🚗 What It Does

- Browse and book mechanic services by car brand
- Manage workshop appointments and repairs
- Track vehicle service history
- Connect car owners with qualified mechanics

## 🛠️ Tech Stack

**Frontend:**
- Next.js
- TypeScript
- Tailwind CSS

**Backend:**
- Node.js
- PostgreSQL
- REST API

**Deployment:**
- Frontend: Vercel
- Backend: Render

## 🚀 Getting Started

\```bash
npm install
npm run dev
\```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## 🗄️ Database

This project uses PostgreSQL as the database, hosted and connected
via Render. Make sure to set the following environment variables:

\```
DATABASE_URL=your_postgresql_connection_string
\```
